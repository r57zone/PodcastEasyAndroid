# PodcastEasy Android
Приложение для прослушивания подкастов и книг в аудио и видео форматах на Android. Просто поместите любые аудио- и видеофайлы в каталог `Podcasts` и наслаждайтесь просмотром и прослушиванием контента.

- Поддержка следующих языков интерфейса: английский, русский, китайский (упрощённый и традиционный), испанский, португальский (бразильский), французский, немецкий, японский, арабский, итальянский, корейский и турецкий.


- Автоматически сохраняет позицию воспроизведения, позволяя продолжить с того места, на котором вы остановились


- Возможность изменять скорость воспроизведения.


- Поддержка закладок. Можно создавать закладки прямо в приложении или импортировать собственные. Закладки хранятся в обычных текстовых файлах (txt), где каждая строка содержит время и заголовок в формате `Время - Заголовок`. Например: `19:17 - Любопытно`.

Название текстового файла должно совпадать с названием соответствующего аудио или видеофайла.


- Встроенный просмотр видео для видеоподкастов. Если видео не требует постоянного внимания, можно слушать подкаст в фоновом режиме и при необходимости нажать кнопку видео, чтобы посмотреть происходящее. Двойное нажатие позволяет увеличить видео, а с помощью свайпов его можно перемещать по экрану.


- Таймер автоматической остановки воспроизведения.
